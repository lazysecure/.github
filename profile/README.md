# lazysecure

**Making information security easier to understand.**

lazysecure is an independent information-security organization focused on security news, technical knowledge, research, and community resources.

We aim to make reliable security information accessible through clear explanations, careful analysis, and responsible research.

## Projects

| Repository | Description |
| --- | --- |
| [hacker-blog](https://github.com/lazysecure/hacker-blog) | Security news, technical articles, and analysis. |
| [hacker-blog-worker](https://github.com/lazysecure/hacker-blog-worker) | Collection and editorial automation for HACKER BLOG. |
| [security-community](https://github.com/lazysecure/security-community) | A space for information-security discussion and community resources. |
| [virus-archive](https://github.com/lazysecure/virus-archive) | A reference archive for virus- and malware-related information. |
| [docs](https://github.com/lazysecure/docs) | Shared documentation for lazysecure projects. |

## Principles

- Prioritize accurate, verifiable information and cite original sources.
- Explain technical security topics clearly without sacrificing precision.
- Distinguish confirmed facts, analysis, and speculation.
- Approach security research responsibly.

## Languages

**English is the primary language** for organization-wide documentation and communication.

Korean is also supported to make our work accessible to Korean-speaking readers and contributors.
