# lazysecure

**Information security, made easier to understand.**

lazysecure is an independent information-security project space focused on security news, technical knowledge, research, and community resources.

## Projects

| Repository | Description |
| --- | --- |
| [hacker-blog](https://github.com/lazysecure/hacker-blog) | A Korean- and English-language security news and analysis publication. |
| [hacker-blog-worker](https://github.com/lazysecure/hacker-blog-worker) | The collection and editorial automation service for HACKER BLOG. |
| [security-community](https://github.com/lazysecure/security-community) | A space for information-security discussion and community resources. |
| [virus-archive](https://github.com/lazysecure/virus-archive) | A project for organizing virus- and malware-related reference material. |
| [docs](https://github.com/lazysecure/docs) | Shared documentation for lazysecure projects. |

## Principles

- Prefer accurate, verifiable information and cite original sources.
- Make technical security topics understandable without sacrificing precision.
- Distinguish confirmed facts, analysis, and speculation.
- Treat security research responsibly.

## Languages

Our public-facing content aims to support both **한국어** and **English**.
